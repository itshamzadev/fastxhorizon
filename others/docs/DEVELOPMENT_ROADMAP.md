# Development Roadmap

1. Complete Phase 1 extraction and compatibility checks.
2. Audit and normalize the central API contract and environment configuration.
3. Integrate the Vital Admin UI with real backend endpoints and server-side RBAC.
4. Implement secure admin sessions, TOTP enrollment/recovery, rate limits, CSRF protection, and audit logs.
5. Expand marketplace entities and workflows: categories, brands, variants, inventory, checkout, COD/manual payments, orders, returns, reviews, promotions, and support.
6. Build independently hosted seller, reseller, and affiliate applications.
7. Perform security, accessibility, performance, deployment, and migration reviews before production work.
